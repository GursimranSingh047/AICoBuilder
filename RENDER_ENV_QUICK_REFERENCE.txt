🔴 MANDATORY VARIABLES (Copy these to Render)
================================================================================

1. API Key (lowercase!)
   openai_api_key=sk-or-v1-YOUR_NEW_KEY_HERE

2. AI Model
   OPENAI_MODEL=gpt-3.5-turbo

3. Secret Key (generate new!)
   SECRET_KEY=YOUR_GENERATED_SECRET_KEY

4. CORS Origins (your frontend URL)
   ALLOWED_ORIGINS=https://your-frontend.vercel.app

5. Debug Mode (production)
   DEBUG=False

================================================================================
🟡 RECOMMENDED (Add for production)
================================================================================

6. Database (if using PostgreSQL)
   DATABASE_URL=postgresql://user:pass@host:5432/db
   (Skip if linking Render PostgreSQL - it's automatic)

================================================================================
⚠️ CRITICAL NOTES
================================================================================

1. Variable name is LOWERCASE: openai_api_key (NOT OPENAI_API_KEY)
2. Generate SECRET_KEY with: python -c "import secrets; print(secrets.token_urlsafe(32))"
3. NEVER use the exposed key: sk-or-v1-d44427a0aa30d890...
4. ALLOWED_ORIGINS: NO SPACES between URLs (comma-separated)
5. Set DEBUG=False in production

================================================================================
✅ VERIFICATION
================================================================================

After deployment, check:
1. https://your-app.onrender.com/health → {"status":"ok"}
2. https://your-app.onrender.com/docs → API documentation loads
3. Render logs show: "GeminiService ready | provider=OpenRouter"

================================================================================
🚨 COMMON MISTAKES
================================================================================

❌ WRONG: OPENAI_API_KEY=... (uppercase)
✅ RIGHT: openai_api_key=... (lowercase)

❌ WRONG: ALLOWED_ORIGINS=https://app1.com, https://app2.com (spaces)
✅ RIGHT: ALLOWED_ORIGINS=https://app1.com,https://app2.com (no spaces)

❌ WRONG: SECRET_KEY=changeme-in-production (default)
✅ RIGHT: SECRET_KEY=xK9mP2vN8qR5tY7wZ3aB6cD1eF4gH0jL (random)

❌ WRONG: DEBUG=True (in production)
✅ RIGHT: DEBUG=False (in production)
